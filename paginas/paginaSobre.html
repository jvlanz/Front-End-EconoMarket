Comparando preços para você economizar.

O EconoMarket nasceu para facilitar a vida dos consumidores de Blumenau, permitindo comparar preços entre supermercados de forma rápida, simples e intuitiva.

Nossa Missão

Missão

Facilitar a comparação de preços entre supermercados, ajudando consumidores a economizar nas compras do dia a dia, economizando tempo e dinheiro.

Valores

Transparência, economia, inovação, simplicidade e compromisso com o consumidor.

Como funciona?

1- Pesquise

Procure pelos produtos de seu interesse.

2- Adicione no carrinho

Adicione os produtos que deseja no carrinho de compras.

3- Economize

Escolha o melhor preço e faça uma compra mais inteligente.

Sobre o Projeto

O EconoMarket foi desenvolvido como Projeto Final do Entra21, com o objetivo de aplicar conhecimentos adquiridos durante a formação em desenvolvimento web.

A plataforma busca oferecer uma solução simples para um problema comum: encontrar os melhores preços entre supermercados de Blumenau. Dessa forma, os usuários conseguem economizar tempo e dinheiro, realizando compras de maneira mais consciente.
